# V36.7 Source Capability Notes

The source capability registry exists to make recruiter result quality and source truth explicit. It is descriptive, not a provider ranking score.

- A source can be useful for capability evidence without supporting person search.
- Native location search and observed profile location are separate capabilities.
- Avatar/profile/contact availability is source-specific and should never be fabricated.
- Public profile identity signals do not authorize silent cross-source merges.
- Publication/artifact sources do not become person records without a separate identity step.
- Source popularity/reputation metrics are never treated as proficiency.
